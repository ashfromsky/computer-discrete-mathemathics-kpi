# Домашнє завдання 13. Мінімізація (карти Карно, метод Квайна)

**Тема:** Алгебра перемикальних функцій
**Максимальна оцінка:** до 3 балів

## Завдання

Для кожної з функцій `f(x1, x2, x3, x4)` нижче (функція дорівнює 0 на
вказаних наборах, і 1 — на решті наборів довжини 4; номер набору — це
двійковий запис `x1x2x3x4`, де `x1` — старший розряд):

1. побудуйте досконалу ДНФ (ДДНФ) і досконалу КНФ (ДКНФ);
2. знайдіть мінімальну ДНФ і мінімальну КНФ **методом карт Вейча–Карно**;
3. знайдіть мінімальну ДНФ і мінімальну КНФ **методом Квайна–Маккласкі**
   (побудуйте імплікантну матрицю, виділіть базисні — ядрові — імпліканти);
4. переконайтесь, що обидва методи дають еквівалентні (за складністю)
   результати;
5. **(тільки для функції a)** за імплікантною матрицею з п. 3 знайдіть
   **усі** тупикові (irredundant) ДНФ функції — тобто всі покриття
   одиничних наборів простими імплікантами, з яких не можна вилучити жодної
   імпліканти без втрати покриття (а не лише одну, з найменшою складністю).
   Порівняйте складність усіх знайдених тупикових ДНФ за критерієм з
   примітки нижче і вкажіть, яка з них (можливо, не одна) є мінімальною.

**a.** `f = 0` на наборах `2, 8, 5, 7, 12, 13, 15`
**b.** `f = 0` на наборах `1, 5, 6, 7, 9, 14, 15`
**c.** `f = 0` на наборах `0, 1, 4, 6, 12, 14, 15`
**d.** `f = 0` на наборах `0, 1, 3, 5, 8, 9, 14`
**e.** `f = 0` на наборах `0, 1, 2, 4, 5, 8, 10`
**f.** `f = 0` на наборах `0, 1, 2, 3, 4, 12, 15`

> Складність формули в цьому завданні: `S = L + I`, де `L` — загальна кількість
> літер (входжень змінних) у формулі, `I` — кількість літер, що входять із
> запереченням. Саме за цим критерієм порівнюйте отримані тупикові та
> мінімальні форми.
