# Домашні завдання — Комп'ютерна дискретна математика

Репозиторій домашніх завдань до курсу **«Комп'ютерна дискретна математика»**
(КПІ ім. Ігоря Сікорського, кафедра обчислювальної техніки).

Наразі тут опубліковано завдання з перших чотирьох тем курсу:

1. Теорія множин
2. Відношення
3. Функції (властивості відповідностей, порядок, ґратки)
4. Алгебра перемикальних функцій (булева алгебра)

Інші теми (скінченні автомати, лінійні автомати, теорія графів,
комбінаторика, завадостійке кодування) уже підготовлені й будуть додані
окремими релізами пізніше.

Завдання складені на основі наявних матеріалів кафедри
(`Home_task_Sets*.doc(x)`, `Home_task_Relations*.doc(x)`,
`Home_task_Boolean_algebra*.doc`, `Discr_exer_BA_Sigorsky.doc`,
`KDM_Zadachi.doc`, `Exercises.doc`) — перегруповані,
очищені від дублювання та доповнені там, де це було потрібно для цілісності
теми.

## Умовні позначення

У завданнях цих блоків використовуються такі позначення:

- `∪`, `∩`, `\` — об'єднання, переріз, різниця множин;
- `∸` — симетрична різниця множин (`A ∸ B = (A \ B) ∪ (B \ A)`);
- `Ā` (риска над буквою) — доповнення множини (або відношення);
- `⊆`, `⊂` — включення (нестроге / строге);
- `×` — декартів добуток;
- `<x, y>` — впорядкована пара;
- `∘` — композиція відношень (`R1 ∘ R2`);
- `R⁻¹` — обернене відношення;
- `f: A → B` — функція з `A` у `B`, `f⁻¹` — обернена функція;
- `ℕ`, `ℤ`, `ℝ` — множини натуральних, цілих і дійсних чисел;
- `sup`, `inf` — супремум та інфімум (найменша верхня й найбільша нижня
  межі) пари елементів у множині з відношенням порядку;
- `∨`, `∧` (або запис без знака, напр. `xy`) — диз'юнкція, кон'юнкція;
- `¬x`, `x̄` — заперечення (інверсія) `x`;
- `→`, `~` (еквівалентність), `⊕` (сума за модулем два) — імплікація,
  еквіваленція, XOR;
- `↓` — стрілка Пірса (АБО-НІ), `|` — штрих Шефера (І-НІ);
- ДНФ / КНФ — диз'юнктивна / кон'юнктивна нормальна форма;
- ДДНФ / ДКНФ — досконала ДНФ / досконала КНФ (інколи ДДКФ — те саме, що
  ДКНФ).

## Довідка: основні тотожності алгебри множин

Використовуються при розв'язанні завдань з розділів «Множини» (спрощення
виразів, рівняння, системи рівнянь). `U` — універсум, `∅` — порожня множина.

1. `A ∪ B = B ∪ A`, `A ∩ B = B ∩ A` — комутативність.
2. `A ∪ (B ∪ C) = (A ∪ B) ∪ C`, `A ∩ (B ∩ C) = (A ∩ B) ∩ C` — асоціативність.
3. `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)`, `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)` — дистрибутивність.
4. `A ∪ ∅ = A`, `A ∩ U = A`.
5. `A ∪ Ā = U`, `A ∩ Ā = ∅`.
6. `A ∪ U = U`, `A ∩ ∅ = ∅`.
7. `∅̄ = U`, `Ū = ∅`.
8. `A ∪ A = A`, `A ∩ A = A` — ідемпотентність.
9. `A ∪ (A ∩ B) = A`, `A ∩ (A ∪ B) = A` — закони поглинання.
10. `(A ∪ B)‾ = Ā ∩ B̄`, `(A ∩ B)‾ = Ā ∪ B̄` — теореми де Моргана.
11. Якщо `A ∪ B = U` і `A ∩ B = ∅`, то `B = Ā`.
12. `Ā = U \ A`.
13. `Ā̄ = A` — інволютивність.
14. `A \ B = A ∩ B̄`.
15. `A ∸ B = (A \ B) ∪ (B \ A) = (A ∪ B) \ (A ∩ B)` — означення симетричної різниці.
16. `A ∸ B = B ∸ A` — комутативність `∸`.
17. `(A ∸ B) ∸ C = A ∸ (B ∸ C)` — асоціативність `∸`.
18. `A ∸ ∅ = ∅ ∸ A = A`.
19. `(A ∸ B)‾ = (A ∩ B) ∪ (Ā ∩ B̄)`.
20. `(A ∩ B) ∸ (A ∩ C) = A ∩ (B ∸ C)`.
21. `A ⊆ B` тоді й тільки тоді, коли `A ∩ B = A`, або `A ∪ B = B`, або `A \ B = ∅`.
22. `A = B` тоді й тільки тоді, коли `A ∸ B = ∅`.
23. `(A ∩ B) ∪ (A ∩ B̄) = A` — закон склеювання.
24. `A ⊆ B`, якщо `A ∪ C ⊆ B ∪ C` для довільної `C`, і навпаки (монотонність об'єднання).
25. `(A₁ ∩ A₂ ∩ … ∩ Aₙ)‾ = Ā₁ ∪ Ā₂ ∪ … ∪ Āₙ` — теорема де Моргана для n множин.
26. `(A₁ ∪ A₂ ∪ … ∪ Aₙ)‾ = Ā₁ ∩ Ā₂ ∩ … ∩ Āₙ` — теорема де Моргана для n множин.
